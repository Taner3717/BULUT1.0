# Kilo Takip Defteri

Kilo vermek isteyenler için günlük takip uygulaması. Tek dosya (`index.html`), kurulum yok — tarayıcıda aç.

Kategoriler:
- ⚖️ Kilo (kg, bel çevresi)
- 😴 Uyku (süre, kalite)
- 😰 Stres (stres, enerji seviyesi)
- 🍽️ Açlık & Beslenme (açlık seviyesi, kalori, su)
- 🏃 Aktivite (adım, egzersiz)

Sekmeler: Günlük Giriş, Tablo (sheets benzeri, kategori başlıklı), Grafikler, Veri/Yedek (CSV ve JSON dışa/içe aktarma).
Veriler tarayıcıda (localStorage) saklanır; CSV'yi Excel/Google Sheets'e aktarabilirsin.
