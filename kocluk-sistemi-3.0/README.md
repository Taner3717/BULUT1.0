# Koçluk Sistemi 3.0

Danışan takip dosyası. Her danışan için `Koçluk Sistemi 3.0 - Şablon.xlsx` kopyalanır;
`Koçluk Sistemi 3.0 - Örnek.xlsx` kurgusal bir danışanla doldurulmuş halidir.

Dosyalar `build.py` ile üretilir (`python build.py`, gereken: `openpyxl`).
Yapıyı değiştirmek için betiği düzenleyip yeniden çalıştır.
